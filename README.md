# שרת MCP ניסיוני - חישוב איחור לסבב

שרת Python קטן עם פעולה אחת: `calculate_experiment_delay(actual_start)`. הוא משווה שעה בפורמט `HH:MM` ל־09:15 ומחזיר איחור בדקות. לדוגמה, `10:07` מחזיר 52 דקות. הוא אינו בודק בפועל קבצים או עבודות עיבוד.

## בדיקה מקומית

```bash
docker build -t experiment-delay-mcp:1.0.0 .
docker run --rm -p 8000:8000 experiment-delay-mcp:1.0.0
```

נקודת הקצה היא `http://localhost:8000/mcp` **רק מהמחשב שבו רץ Docker**. אפשר לבדוק את הפעולה עם MCP Inspector או לקוח MCP אחר שתומך ב־Streamable HTTP. בקשה פשוטה בדפדפן אינה בדיקת MCP תקינה.

## חיבור ל־DIALX

1. יש לפרוס את התמונה כשרת MCP בנקודת רשת שאליה DIAL Core יכול להגיע, למשל באמצעות מנגנון MCP Containers בארגון או שירות פנימי מאושר. אין להזין `localhost` ב־DIALX כאשר השרת רץ במחשב האישי.
2. בקש ממנהל הסביבה את כתובת הקצה המדויקת לאחר הפריסה, כולל הנתיב `/mcp`, ואת דרישות האימות. אין להניח ש־HTTP ללא אימות מתאים מחוץ לרשת בדיקה פרטית.
3. ב־Studio > Toolsets > Create toolset, הזן Endpoint URL של השרת הנגיש, הגדר Authentication לפי הפריסה, וב־Allowed tools הזן `calculate_experiment_delay`.
4. הוסף את ה־Toolset לסוכן הראשי דרך Add MCP tool. בשיחה חדשה שאל: "הסבב התחיל בפועל ב־10:07. חשב באמצעות כלי הניסוי כמה דקות איחור היו לעומת 09:15." התוצאה הצפויה: 52 דקות. ב־Debug ודא קריאת כלי עם `actual_start=10:07`.

## גבולות הניסוי

השעה היא נתון מקומי באותו יום, ללא אזור זמן או חציית חצות. השרת אינו כולל חיבור למסד נתונים, קבצים או שירותי דואר. הוא מיועד ללימוד שרשרת הקריאה מ־DIALX ל־MCP, לא לפריסה ציבורית ללא מעטפת אבטחה.
